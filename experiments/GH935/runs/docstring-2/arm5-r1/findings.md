Confirmed findings:

- **Say how many you mean** — "Where a key holds a dictionary in both `base` and `overlay`, the two dictionaries are merged, and the same rule applies at every level below." "A key" reads as one specific key, but the meaning is any key meeting the condition — the guide's own contrast ("Any user can delete a record" vs. "A user can") calls for "any key" here.

- **Say how many you mean** — "A key that appears only in `base` keeps its value, and a key that appears only in `overlay` is added." Both instances of "a key" read as one specific key rather than every/any key meeting the condition.

- **Say how many you mean** — "so a plain value in `overlay` will drop a whole dictionary from `base`". "A plain value" reads as one specific value rather than the general case of any plain value.

- **Use active voice** — "a key that appears only in `overlay` is added". This is passive and never says what adds the key.

- **Use a small vocabulary** — the return value is named "a new dictionary" in the first sentence, then "the result" later ("The result is not a deep copy" ... "Copy the result deeply first..."). Swapping terms for the same referent makes a reader look for a new meaning.
