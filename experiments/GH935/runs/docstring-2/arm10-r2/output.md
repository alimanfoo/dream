The function walks `base` and `overlay` together and builds a new dictionary from the two. Where both supply the same key, `overlay` wins; where a key appears only in `base`, it survives — and it survives at every level of the nesting, not merely the top. What comes back is therefore an additive update to `base`, not a replacement of it.

The walk descends only when both sides offer a dictionary at the same key. That is the one condition for merging, and every other pairing ends the descent: a dict in `base` against a scalar in `overlay`, or a scalar against a dict, resolves by taking the `overlay` value wholesale. Lists are values here rather than containers, so a list in `overlay` replaces the list in `base` outright; it is never concatenated onto it or merged element by element. Nor can `overlay` ask for anything to be taken away. A value of `None` is just another value, so it sets the key to `None` instead of removing it, and there is no way to express a deletion at all.

Neither input comes back changed, but the result is not a deep copy of them either. Any subtree that `overlay` never reaches is shared by reference with `base`, and the values that do come from `overlay` are inserted by reference in turn. The returned structure thus overlaps both inputs: mutate it in place and the change is visible through `base` or `overlay`, and mutating either of those is visible through the result. Copy explicitly if you need the three to be independent.

The test for "is this a dictionary?" is an `isinstance` check against `dict`, and that has two consequences. Subclasses of `dict` — an `OrderedDict`, a `defaultdict` — pass the check and are merged, but the merged subtree is built as a plain `dict`, so the type and whatever behaviour came with it are lost. Mapping types that do not subclass `dict` fail the check instead, and are treated as opaque values to be replaced.

Finally, the recursion tracks the nesting of the inputs, one frame per level. Structures nested deeply enough can exhaust the interpreter's recursion limit, and a self-referential dictionary gives the walk no bottom to reach, so it will not terminate.
