Two confirmed findings:

- **"the list it replaces"** breaks *Write to be understood*: it drops the relative pronoun on an object relative clause ("the list [that] it replaces"), which the guide says to keep rather than drop.

- **"Copy the result deeply if you need it to stand on its own."** breaks *Giving instructions*: the condition governing the imperative should come before it, not after — as in the guide's own "If the file is read-only, skip it" example.
