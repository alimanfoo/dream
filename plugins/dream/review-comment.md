# Review comment

Post a review's findings, and what you did about each one, as one pull request
comment. Use this shape:

```text
## {heading}

> {the finding, verbatim}

{your response}

> {the finding, verbatim}

{your response}

...and so on, one block per finding.
```

Quote each finding verbatim, so the reader can tell the review's words from
yours.

If a review returned no findings, post the heading and one line saying so.
